# 장진욱 · Unity 게임 클라이언트 개발자

게임을 좋아하는 플레이어이자, 재미있는 게임을 만들고 싶은 개발자입니다.

Unity와 C#으로 턴제 전투, 멀티플레이, 3D 편집 도구를 개발해 왔습니다. 기능을 만들 때는 유저가 조작을 쉽게 이해할 수 있는지, 행동에 대한 피드백이 명확한지, 플레이가 재미있는지를 함께 고민합니다. 기획과 디자인 논의에서도 의견을 제안하고, 팀원들과 다듬어 가는 개발을 좋아합니다.

## 개발하며 중요하게 생각하는 것

**문제를 이해하고 해결하기**  
턴 순서와 캐릭터 상태가 어긋나는 문제, 편집 도구의 실행 취소와 저장 데이터가 맞아야 하는 문제, 멀티플레이에서 좌표 기준이 달라지는 문제를 다뤘습니다. 겉으로 보이는 현상뿐 아니라 상태와 데이터가 바뀌는 흐름을 살펴보며 해결 방법을 찾습니다.

**플레이하는 사람의 입장에서 생각하기**  
버튼을 눌렀을 때 무엇이 달라졌는지, 지금 어떤 행동을 할 수 있는지 알기 쉬운 게임을 만들고 싶습니다. 구현 방식뿐 아니라 UI/UX와 게임의 재미에 대해서도 함께 이야기합니다.

**직접 통제할 수 있는 범위에서 AI 활용하기**  
Codex와 하네스를 사용해 작업 범위와 지켜야 할 조건을 정합니다. 해결할 문제와 설계 방향은 직접 판단하고, AI가 제안한 코드는 기존 구조에 맞는지 검토합니다. 제가 이해하고 설명할 수 있으며, 수정 결과를 확인할 수 있는 범위에서 활용하는 것을 기준으로 삼습니다.
